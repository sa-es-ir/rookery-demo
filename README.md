# rookery-demo

A tiny to-do CLI, worked on in public by [Rookery](https://rookery.run): every issue here is
planned, approved and implemented through Rookery's loop, and every PR shows the plan, the
tasks and the review that produced it.

```
python todo.py add "write docs"
python todo.py done 1
python todo.py list
python test_todo.py
```
